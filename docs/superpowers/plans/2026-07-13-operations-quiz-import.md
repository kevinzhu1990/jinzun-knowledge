# 各平台运营题库导入计划

## 处理规则

1. 使用用户提供的 `各平台运营题库130题_seed.json` 作为唯一输入。
2. 按 `OPS-PDD`、`OPS-TB`、`OPS-DY`、`OPS-JD`、`OPS-WX` 前缀校正平台题库归属。
3. 按规范化题干去重；重复题写入移除清单，不改写保留题干。
4. 备份导入前岗位题库，移除原有低质量运营旧题，保留其他岗位题目。
5. 保留原题字段，不加入处罚金额、赔付比例或固定活动时限。
6. 将版本更新为 `20260713-operations-quiz1`，并通过前端题库筛选进入对应平台题库。

## 发布门槛

- 运营题ID唯一、平台题量为30/30/30/20/20。
- 题干和选项通过质量检查。
- 红线题必须 `mandatory=true`。
- `npm.cmd run verify` 与运营专项测试全部通过。
