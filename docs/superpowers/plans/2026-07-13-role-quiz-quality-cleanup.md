# 岗位规则题库质量清理计划

## 目标

下线通过固定模板和场景编号批量生成的岗位规则题，保留原有156题供人工复核；正式考试只允许来源已核验、题目已人工批准、无来源冲突且无语义重复的题目。

## 已执行步骤

1. 归档清理前的601题到 `outputs/role_quiz/archive/岗位学习考核题库-role-rules3.json`。
2. 从正式题库移除445道 `RULE-` 自动题，写入拒绝清单并记录拒绝原因。
3. 新增10个平台/岗位规格文件目录；未取得后台规则正文的规格保持待核验，不进入正式考试。
4. 新增题干规范化、字符3-gram相似度、选项集合和同岗位模块条款重复检测。
5. 为原156题生成逐题审计报告，统一设置人工审核门槛。
6. 后端正式考试抽题增加 `verified + effectiveForFormalExam + approved + no conflict + no duplicate` 门槛。
7. 页面学习题库增加已审核、待核验、内部SOP、官方平台规则、国家法律等状态标签。

## 发布门槛

- 生成器重复执行必须保持拒绝清单和归档不丢失。
- `npm.cmd run verify` 全部通过。
- 任何待核验或未人工批准题不得进入 `/api/exam-start` 的正式考试池。
- 用户提供的培训文件和拼多多赔付截图未取得可核验原件/官方规则前，不生成数字处罚题。
