# 各平台运营题库扩充设计

## 1. 目标

在现有《岗位学习考核题库》中新增一套可直接用于员工学习与考试的“各平台运营题库”，覆盖拼多多、天猫/淘宝、抖音电商、京东和视频号。

本次目标不是继续堆叠模板题，而是新增真实、可判断、能反映运营能力的题目，并清除现有错误的模板化运营规则题。

## 2. 题量与平台分布

| 平台 | 新增题量 |
|---|---:|
| 拼多多 | 30 |
| 天猫/淘宝 | 30 |
| 抖音电商 | 30 |
| 京东 | 20 |
| 视频号 | 20 |
| 合计 | 130 |

## 3. 题型结构

整体题型比例：

- 基础知识题：30%
- 数据诊断题：30%
- 真实场景题：30%
- 运营红线题：10%

每个平台都必须同时包含：

1. 商品基础与发布
2. 流量与点击
3. 转化与承接
4. 活动与价格
5. 库存与履约
6. 售后与评价
7. 数据复盘
8. 合规边界

## 4. 题目质量规则

每道题必须满足：

1. 有明确业务事实，不得只写抽象主题。
2. 有唯一正确答案。
3. 三个错误选项必须是现实中可能出现、但明确不正确的运营动作。
4. 不得使用“场景编号”制造差异。
5. 不得通过交换选项顺序制造重复题。
6. 不得重复使用固定错误选项。
7. 不得将同一个题干仅替换平台名称后重复使用。
8. 同一知识点最多3道题，且必须分别考查识别、处理和复盘。
9. 不使用未经确认的处罚金额、赔付比例、报名时间和时效数字。
10. 涉及平台规则的题目必须标明来源状态。

## 5. 平台题目重点

### 5.1 拼多多

重点覆盖：

- 商品标题、属性、SKU、价格和主图一致性
- 曝光、点击率、转化率诊断
- 活动报名与价格力
- 品质退款与售后原因分析
- 真实发货、物流和缺货风险
- 客服响应与服务体验
- 评价管理和禁止诱导好评
- 平台外导流和私下交易

### 5.2 天猫/淘宝

重点覆盖：

- 搜索流量与标题优化
- 主图点击率和详情页承接
- 活动价格、原价和优惠表达
- 赠品、快递、发货和客服承诺
- 发票、评价和售后协同
- 店铺数据诊断
- 商品信息真实性
- 违规宣传和消费者隐私

### 5.3 抖音电商

重点覆盖：

- 短视频播放、商品点击和成交关系
- 直播间进入率、停留、商品点击和支付转化
- 巨量千川投放诊断
- 商品卡与内容一致性
- 主播价格、库存和赠品表达
- 普通食品功效与特殊人群宣传边界
- 售后、退款和商品评分
- 素材衰退与投放复盘

### 5.4 京东

重点覆盖：

- 商品信息和搜索承接
- 发货、物流单号和揽收
- 少件、错件和多包裹
- 页面与客服承诺
- 评价和售后处理
- 活动、库存和履约能力
- 发票和交易信息一致性
- 经营数据复盘

### 5.5 视频号

重点覆盖：

- 短视频内容与商品点击
- 直播停留与成交承接
- 微信生态中的咨询转化
- 商品链接、价格和SKU一致性
- 私域信任与复购
- 发货和售后承诺
- 直播复盘
- 平台内合规交易

## 6. 数据结构

新增题目沿用现有岗位题库结构，并至少包含：

```json
{
  "id": "OPS-PDD-0001",
  "bank": "运营-拼多多",
  "role": "运营",
  "platform": "拼多多",
  "module": "数据诊断",
  "type": "单选题",
  "difficulty": "基础",
  "riskLevel": "practice",
  "question": "具体题干",
  "optionA": "",
  "optionB": "",
  "optionC": "",
  "optionD": "",
  "answer": "B",
  "answerText": "",
  "explanation": "",
  "answerBasis": "internal_sop | official_rule | law",
  "verificationStatus": "approved | pending",
  "effectiveForFormalExam": true,
  "humanReviewStatus": "approved"
}
```

规则：

- 经营方法题可使用 `internal_sop`。
- 平台规则题使用 `official_rule`。
- 法律合规题使用 `law`。
- 无法确认的规则题必须标记 `pending`，且不得进入正式考试。

## 7. 旧题清理

本次必须同步清理现有错误的模板化运营题：

- 题干含“在处理某场景时”且没有具体事实；
- 题干含“场景编号”；
- 同一题意仅替换平台或主题；
- 来源与题目不匹配；
- 固定错误选项反复出现；
- 无具体规则依据却标记为红线；
- 仅靠常识即可判断、无法体现运营能力。

被移除的题目写入归档文件，不直接丢失。

## 8. 重复检测

新增验证必须识别：

- 完全重复题干；
- 删除平台名后仍重复的题干；
- 仅交换选项顺序的题；
- 同一问题只替换商品名或数字；
- 同一正确答案、同一解释、同一知识点的高度相似题。

建议采用规范化文本加字符3-gram相似度，阈值为0.82。

## 9. 正式考试规则

正式考试只抽取：

```text
verificationStatus == approved
AND effectiveForFormalExam == true
AND humanReviewStatus == approved
```

运营岗位考试建议抽题比例：

- 平台基础题：30%
- 数据诊断题：30%
- 场景题：30%
- 合规红线题：10%
